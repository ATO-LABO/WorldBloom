    世界を作る¶

    「世界」は、GA 実験の元になる舞台設定（人物・場所・時間・目標の結末）一式です。この画面で作った世界を使って、実行設定から GA 実験を回します。

    新しい世界を作る¶

    世界一覧の「新しい世界を作成」から始めます。カードには保存済みの概要、人物数、場所数、期間、主人公・敵役が表示され、世界名や人物で検索できます。

    入口は4つあります。

    • 既存の世界から始める: 元の世界を選び、関連ファイルやフォーム未対応の項目を保持した別の下書きを作ります。元の世界は変更しません。
    • ZIPから始める: ZIPから下書きを作ります。取り込み手順を参照してください。
    • 保存した下書きを再開: 内容と編集段階を読み込みます。再開だけではAIへの相談・検証・採用は行いません。
    • 新規作成: 名前・概要から下書きを用意します。未完成の入力も保存できます。

    作成は次の3段階です。

    1. ① 下書きを用意: 名前（120文字まで）と概要（8000文字まで）を入力します。任意のジャンルや「世界の脅威への対応」は制作の手がかりで、選択するだけでは生成や実行条件の設定は行いません。
    2. ② 内容を整える: 人物・関係・場所・持ち物・時間・目標などを手入力で整えます。AIへの相談は任意です。項目を指定して修正案を作り、差分を確認して「この案を下書きに採用」で反映します。新規下書きでは世界全体の別案も依頼できますが、現在の手修正は別の保存済み下書きに残します。
    3. ③ 確認して採用: 「設定と実行入力を確認」で検証し、未設定項目・初期値・非対応の詳細を読みます。確認チェックを入れて新しい世界として保存します。採用は元の世界への上書きやGA実行ではありません。検証成功も結末への到達や面白さを保証しません。

    AIを使う場合¶

    AIの設定を先に確認してください。AI入力は明示的に開始したときだけ実行されます。目的を解釈 → 世界設定を生成 → 内容を確認、という3段階の方式では最大3回のAI呼出しが表示されます。画面の3段階の編集手順とは別の処理です。

    AIが待機中でも手入力・下書き保存・採用はできます。ソース版で実AIを利用するには、接続先・モデル・費用を確認したうえでサーバー起動時に --control と --world-draft-live を指定します。設定画面でモデルを保存するだけでは待機モードは解除されません。

    通信が途切れたり結果が不明になった場合は「AI入力の状態を確認」で送信済みの結果を確認します。自動再送は行いません。手入力に戻ったり別の下書きへ移った後に、古い結果で現在の入力を上書きしない仕組みです。

    世界設定画面¶

    保存した世界を「世界を開く」から開くと、共通のカテゴリで設定を確認・編集できます。

    カテゴリ 内容
    概要と物語の前提 世界の名前・概要・役割・結末、拡張の提案
    話の説明 初期物語の導入文・開始時点の状態
    登場人物と関係 人物の設定・初期位置・数値、相関図・関係表
    場所と移動 場所とつながり
    持ち物と情報 開始時点の所持・知識と入手方法
    時間と出来事 期間・時間帯・予定イベント
    行動設定 行動の種類や使用条件
    世界のルール 状態・条件、目標、対処、計画、金銭など
    確認・調査 確認の概要、結末までの経路、調査の条件、世界のレビュー
    設定ファイル YAMLの直接編集

    「話の説明」から「初期物語」を開き、導入文や開始時点の状態を確認できます。「概要と物語の前提」内の「初期物語」カードや「導入文を編集」も引き続き使えます。既存の #screen=story URLにも対応しています。

    「確認・調査」の「結末までの経路」は、結末までの段取りを最大3本調べる読み取り専用の機能です。道筋層や目標の形式によっては非対応です。道筋層を参照してください。

    項目ごとに保存します。保存しても過去の実行結果は変わりません。下部には不足があれば「未設定の項目を確認 →」、揃っていれば「実行条件を決める →」（実行設定）が表示されます。閲覧専用のViewerでは編集できません。

    体力と所持金¶

    「行動設定」から体力管理の設定を確認できます。有効な世界では、最大体力・開始時点の体力・休息や睡眠の回復量、行動ごとの消費量の増減を設定します。体力管理を無効にしても設定値は保持され、時間・場所・負傷・死亡の条件は残ります。

    通貨を設定した世界では、人物の「開始所持金」から金額を編集できます。通貨が未設定なら先に金銭設定へ進みます。これらも以後の実行の初期設定です。

    詳細設定・設定ファイルの編集窓口¶

    左メニューの「世界のルール」や「設定ファイル」から詳細編集へ進めます。役割と結末、状態・条件、達成・失敗・判定期間、目的と対処、目的の分解と再計画、金銭設定、状況ごとの定石、行動図鑑などを確認できます。

    ジャンル（テンプレート）は複数の世界が共有する行動と結果のルールです。ジャンルの管理画面では既存のものを「複製して編集」してから変更します。元のジャンルを利用する世界へ意図しない変更を及ぼさないようにしてください。

    人物関係図¶

    「登場人物と関係」には「一覧」「相関図」「関係表」の3つの表示があります。

    • 相関図: 人物どうしの関係を有向グラフとして表示します。人物は所属（affiliation。未設定なら開始時の居場所）ごとに色分けされ、主人公の所属を起点にグループが並びます。「全体」（登場人物すべて）と「人物フォーカス」（1人を選び、直接関係／2段階／すべて、から表示範囲を絞る）を切り替えられ、「好意」「反感」「中立」や所属でも絞り込めます。人物をクリックすると詳細パネルが開き、所属・直接関係の人数・概要・主な関係（上位6件）を確認できます。「関係を数値で確認」（折りたたみ）で、affinity（親しさ）・awareness（認知）を含む数値付きの一覧に切り替えられます
    • 関係表: 相関図とは別のタブで、人物×人物の行列として全員の関係を一望できます
    • 相関図・関係表のどちらでも、編集可能な世界なら関係の行に「ラベルを編集」ボタンが出ます。一方向（source→target）ごとにラベル文字列（120文字まで）を設定・削除できます（数値の affinity/awareness 自体はここでは編集できません）
    • 人物の所属（affiliation、120文字まで、任意）は、「一覧」タブで人物を選び「人物を編集」ダイアログから設定します。相関図の色分け・グループ分けはこの値を使います

    相関図で設定に不備（関係の形式が壊れているなど）があれば、「設定の確認」（折りたたみ）に件数と内容が表示されます。

    予定イベントと強制行動¶

    「時間と出来事」では、実行日数・1日の時間帯に加えて、世界の予定イベント（scheduled_events）を確認・編集できます。予定イベントは、指定した日・時間帯に自動で起きる出来事（対象・効果・ラベル）です。

    このうち強制行動（force_action）を持つイベントは、その時間帯の対象の行動そのものを、指定した動詞・引数へ強制的に差し替えます（例: 3日目の朝、主人公を強制的に「道中」へ移動させる）。画面のフォームは、動詞ごとに指定できる引数の種類・個数を案内します。詳しい仕様（バリデーションの規則など）はテンプレートを参照してください。

    世界の自己拡張¶

    GA 実験を回す中で、人物の行動が同じ場所で何度も「空振り」する（例: 調べても何も出てこない）ことが続くと、WorldBloom はその世界に足りない要素（場所・品・事実など）を自動的に提案します。この提案は世界設定を直接書き換えず、承認するまで反映されません。

    世界設定画面の「概要と物語の前提」、および該当する実験の結果画面に、提案ごとのカードが表示されます。カードには次の情報があります。

    • 何が増えるか: 追加される場所・品・事実の内容（例: 「場所『◯◯』を『△△』の一部として足す」）
    • きっかけ: どの実験のどの場所でどの行動が何回中何回空振りしたか
    • 検査の結果: 静的ゲート（ルール違反の有無）と試走（holdout seed での再現確認・契約検査・到達の変化）の結果
    • 書き手の説明: 提案を作った側の説明文（参考情報。判断は上の検査結果で行う）

    承認できるのは、静的ゲートを通過し、holdout seed で試走済みで、状態が「人の確認待ち」になっている提案だけです。承認時は10文字以上の承認理由を入力します。承認すると、その提案はその世界の以後の実行に反映されます。却下すると提案は使われません。

    承認済みの拡張は「後から生まれたもの」節に適用順で並びます。まとめて「承認済みの拡張をすべて提案中へ戻す」こともできますが、1件だけ戻すことはできません（あとの承認は前の承認済み拡張がある前提で検査されているため）。戻すと、戻した分はすべて検査からやり直しになります。
