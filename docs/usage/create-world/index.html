    世界を作る¶

    「世界」は、GA 実験の元になる舞台設定（人物・場所・時間・目標の結末）一式です。この画面で作った世界を使って、実行設定から GA 実験を回します。

    新しい世界を作る¶

    ホーム画面（世界を選ぶ）の ＋ 新しい世界を作る から開きます。

    作成方法は2通りから選びます。

    • 新しく作る: 空の世界から始めます。ジャンルは共通の基本ルール（basic）が初期値になり、あとから変更できます。
    • 既存の世界から作る: 一覧から作成元の世界を選び、その世界の設定をコピーします。作成元の世界自体は変わりません。コピー時はジャンルも一覧（検索ボックス付き）から選び直せます。

    共通の入力項目:

    • 世界の名前（必須、120文字まで）
    • 世界の概要（任意、8000文字まで。「新しく作る」のときだけ入力欄が出ます）
    • 詳細設定を開くと 世界ID が編集できます。半角英数字・ハイフン・アンダースコアのみ（1〜96文字）で、既定では world- に続けてランダムな12文字が自動入力されます

    作成すると、その世界の世界設定画面（次項）に進みます。人物・場所・初期物語はこの時点では空で、あとから設定します。

    世界設定画面（世界ごとのタブ）¶

    世界を開く（またはホームの世界カードから「世界を開く」）と、次の5つのタブで設定を確認・編集します。

    タブ 内容
    世界の概要 名前・概要の編集。世界の自己拡張（下記）で承認済み・提案中の変更点があれば、ここに表示されます
    登場人物 人物ごとのパラメータ（9指標）や初期位置などを確認・編集
    場所 場所（ゾーン）の一覧と、場所どうしのつながり
    初期物語 導入文（開始時点の状況）の編集
    時間 実行日数・1日の時間帯の区切り

    編集は項目ごとに保存できます。保存しても、その世界で過去に実行した結果は変わりません（次回以降の実行から新しい設定が使われます）。

    画面下部のフッターには、未設定の項目（登場人物・場所・主人公・敵役・目標の結末・人物の初期位置のいずれか）があれば「未設定の項目を確認 →」、すべて揃っていれば「実行条件を決める →」（実行設定へ）のボタンが出ます。

    閲覧専用の Viewer では、この画面は表示のみで保存ボタンは機能しません（Studio でのみ編集できます）。

    詳細設定・設定ファイルの編集窓口¶

    世界設定画面の左メニュー下にある「詳細設定・設定ファイル ↗」から、より踏み込んだ編集に進めます。4つの区画があります。

    • 役割と結末: 主人公・敵役などの役割、目標の結末の設定
    • 状況ごとの定石: ジャンルが持つ定石（何がどんな状況で起きやすいか）を、この世界の人物に当てはめて確認
    • 行動図鑑: 人物が選べる行動の一覧
    • 設定ファイル: 世界フォルダ内の YAML ファイルを直接編集

    テンプレート（ジャンル）自体の編集は、ホームの「ジャンル」タブ→ジャンルを開く、または「＋ 新しいジャンルを作る」から行います。ジャンルは複数の世界で共有される、行動とその結果を決める共通ルールです。既存のジャンルは「複製して編集」で複製してから変更できます（元のジャンルを使っている他の世界には影響しません）。

    世界の自己拡張¶

    GA 実験を回す中で、人物の行動が同じ場所で何度も「空振り」する（例: 調べても何も出てこない）ことが続くと、WorldBloom はその世界に足りない要素（場所・品・事実など）を自動的に提案します。この提案は世界設定を直接書き換えず、承認するまで反映されません。

    世界設定画面の「世界の概要」タブ、および該当する実験の結果画面に、提案ごとのカードが表示されます。カードには次の情報があります。

    • 何が増えるか: 追加される場所・品・事実の内容（例: 「場所『◯◯』を『△△』の一部として足す」）
    • きっかけ: どの実験のどの場所でどの行動が何回中何回空振りしたか
    • 検査の結果: 静的ゲート（ルール違反の有無）と試走（holdout seed での再現確認・契約検査・到達の変化）の結果
    • 書き手の説明: 提案を作った側の説明文（参考情報。判断は上の検査結果で行う）

    承認できるのは、静的ゲートを通過し、holdout seed で試走済みで、状態が「人の確認待ち」になっている提案だけです。承認時は10文字以上の承認理由を入力します。承認すると、その提案はその世界の以後の実行に反映されます。却下すると提案は使われません。

    承認済みの拡張は「後から生まれたもの」節に適用順で並びます。まとめて「承認済みの拡張をすべて提案中へ戻す」こともできますが、1件だけ戻すことはできません（あとの承認は前の承認済み拡張がある前提で検査されているため）。戻すと、戻した分はすべて検査からやり直しになります。
