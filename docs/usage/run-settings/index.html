    実行設定¶

    世界設定画面の「実行条件を決める →」、またはホームの「＋ 新しい世界を作る」完了後に開く画面です。GA 実験を1回どう回すかを決めて「設定」として保存し、次の画面で実行します。GA 実験そのもの（候補の生成・重み計算・進化）は LLM を呼び出しません。ただし合理性 κ（下記04.）を 0 より大きくすると、GA の各決定ごとに判定用のローカル LLM（Ollama）を呼び出します——1ラン（個体×seed の組）あたり数十秒以上かかり、GPU を使います。あらすじ・本文の生成は別段階です（文章を生成するを参照）。

    新規作成時は、世界とジャンルが決まっていれば設定名が自動入力されます（例: 2026-09-25 10:00 detective - 星を運ぶ街。ジャンル部分はジャンルID）。保存済みの条件を選んで複製することもできます（複製時は世界・ジャンルは固定です）。

    01. 世界と結末¶

    • 世界: 実行対象の世界を選びます
    • 目指す結末: 既定では世界に設定した「目標の結末」を使います。「別の結末を指定」を選ぶと、結末IDをカンマ区切りで指定でき、そのいずれかに到達すれば成功として扱われます

    02. 探索の規模¶

    項目 意味 既定値
    世代数 GA の世代数（generations） 20
    1世代の個体数 1世代あたりの個体数（population） 100
    個体ごとの評価回数 個体1体を評価するシード数（seeds） 3

    1世代あたりの実行回数は「個体数 × seed数」です。世代を重ねるほど良い経緯が残っていきますが、実行時間もその分伸びます。

    03. 保存と進化¶

    結果の保存（keep）は3通りから選びます。

    値 内容
    すべての結果 all
    結末に到達した結果 reached（既定）
    個体ごとに代表1件 exemplar

    結末に到達した個体が1件もない場合は、keep の設定にかかわらず最良個体の結果を保存します。

    世界の拡張（world_expansion、世界の自己拡張と対応）:

    値 内容
    しない（既定） off。世界は変えません
    検知のみ detect。世界は変えず、行動が空振りした場所・行動を集計するだけです
    承認済みの拡張を適用 expand。承認済みのパッチ（projects/<world>/patches/*.yaml）を実行前に適用してから、同じ集計を行います

    そのほかの切り替え項目:

    • 説明記録（record_explanations、既定オン）: 候補の選択・根拠・代償・転機をあとから確認できるように記録します
    • 共進化（coevolve、既定オフ）: 敵役側の個体群も並行して進化させます。オンにすると評価回数が2倍になります（主人公パス＋敵役パス）
    • メタ進化（meta_evolution、既定オフ）: 9つの数値遺伝子に加えて、ルールごとの有効・無効も探索します

    04. 合理性（主人公がどれだけ筋の通った手を選ぶか）¶

    ジャンルに rationality.yaml（LLM による合理性判定・Jev）があれば、判定用モデルに今接続できるかどうかに関わらず常にこの区画が表示されます。接続の可否が変えるのは κ の既定値だけです。新規作成時、判定が実際に使える状態なら κ の既定値は 0.6（実行時間の上限も自動的に 21600 秒へ）、使えない場合は 0（オフ）になります。κ を上げるほど、不合理な手段が選ばれにくくなります。0 にすると合理性判定は行われず、Ollama への呼び出しも発生しません。κ を 0 より大きくした場合、1ラン約90秒（判定器の呼び出し込み）を目安に、実行時間の見込みが画面に表示されます。

    05. 道筋（寄り道の抑え方）¶

    ジャンルに route.yaml（道筋層。詳しくは道筋層）があれば表示される区画です。主人公が結末へまっすぐ向かう強さを ρ（0〜1） で指定します。0（エンジン・CLI・テンプレートの既定）では道筋層そのものが動かず従来どおり無変調、1 に近いほど理由のない寄り道をほとんど選ばなくなります。身体の都合・思い込みによる寄り道は ρ を上げても罰されません。動機表（motives.yaml）に一致した寄り道は、その動機に効く遺伝子の強さに応じて扱いが変わり、弱い個体ではほぼ「理由なし」と同じ扱いまで抑えられます。

    新規作成画面、および route.yaml があるテンプレートでのホーム・世界画面の「1クリックで実行」ボタンでは、ρ に既定で 1.0 が入ります（κ と違い、ρ は計算コストを増やさないため）。複製・編集では保存済みの値がそのまま使われます。ジャンルを切り替えて対象テンプレートに route.yaml が無くなった場合、ρ は自動的に無効（未指定）に戻ります。

    詳細設定¶

    04.（と、道筋が表示される場合は05.）の区画のあとに、折りたたみで表示される項目です。

    • ジャンル: 新規作成時のみ選べます（複製時は複製元と同じ）
    • 乱数の開始値（seed_base、既定 0）・進化の乱数（ga_seed、既定 1）
    • 並列数（GA を同時に何プロセスで進めるか）はここではなく ⚙ 全体設定の「計算」 で指定します（設定を参照）
    • 実行時間の上限（execution_limits.wall_seconds、既定 3600秒）: この秒数を超えると実行を打ち切ります。κ（合理性判定、上記）を使う場合は既定で 21600 秒に引き上がります

    実行開始¶

    保存すると、その設定の実行条件画面（/configs/<設定ID>）に進みます。「この条件で実行へ →」を押すと実行画面（/jobs）が開き、「この設定で GA を回す」を押すと実行が始まります。実行中は世代の進捗バーが表示され、実行を止めても閉じた世代までの結果は残ります。実行が終わったら、同じ画面から「同じ設定でもう一度回す」で再実行できます。
