    CLI¶

    すべて python <スクリプト> ... の形でリポジトリ直下から実行します。ヘルプ全文は各スクリプトの --help から生成しています（docsite/gen_cli.py。スクリプト側の引数を変えたら再生成してください）。jev_*.py・rationality_probe.py は開発用の計測スクリプトなのでここには含めません。

    scripts/evolve.py — GA 実験を実行する¶

    決定論的な MAP-Elites を1回走らせます。--project（世界）・--template（ジャンル）・--out（出力先）が必須です。

    usage: evolve.py [-h] --project PROJECT --template TEMPLATE --out OUT [--generations GENERATIONS]
                 [--population POPULATION] [--seeds SEEDS] [--seed-base SEED_BASE]
                 [--ga-seed GA_SEED] [--processes PROCESSES] [--keep {all,reached,exemplar}]
                 [--coevolve] [--meta-evolution]
                 [--target-ending TARGET_ENDING [TARGET_ENDING ...]]
                 [--record-explanations | --no-record-explanations]
                 [--world-expansion {off,detect,expand}] [--kappa KAPPA]
                 [--rationality-backend {ollama,none}] [--rationality-method {noul,choice}]
                 [--rationality-model RATIONALITY_MODEL]
                 [--rationality-num-ctx RATIONALITY_NUM_CTX]
                 [--rationality-table RATIONALITY_TABLE]
                 [--rationality-max-calls RATIONALITY_MAX_CALLS] [--route-rho ROUTE_RHO]
                 [--resume] [--resume-allow-code-change]

Run deterministic MAP-Elites evolution.

options:
  -h, --help            show this help message and exit
  --project PROJECT
  --template TEMPLATE
  --out OUT
  --generations GENERATIONS
  --population POPULATION
  --seeds SEEDS
  --seed-base SEED_BASE
  --ga-seed GA_SEED
  --processes PROCESSES
  --keep {all,reached,exemplar}
  --coevolve            Coevolve a separate antagonist population and archive.
  --meta-evolution      Evolve per-rule enable bits in addition to the nine scalar genes.
  --target-ending TARGET_ENDING [TARGET_ENDING ...]
                        Override target ending ids; any listed ending counts as reached.
  --record-explanations, --no-record-explanations
                        Record bounded choice candidates for the explanation viewer (default: on).
  --world-expansion {off,detect,expand}
                        Off leaves the world unchanged; detect aggregates zone/verb whiff triggers
                        after evolution ends; expand applies this project's approved patches
                        (projects/<name>/patches/*.yaml) before the run, then detects.
  --kappa KAPPA         WB-JEV-001 Stage 2: override templates/<genre>/rationality.yaml's kappa (0
                        disables the rationality layer; that is the template default).
  --rationality-backend {ollama,none}
                        Override rationality.yaml's judge backend.
  --rationality-method {noul,choice}
                        Override rationality.yaml's judge method (yes/no vs multiple-choice).
  --rationality-model RATIONALITY_MODEL
                        Override rationality.yaml's judge model name.
  --rationality-num-ctx RATIONALITY_NUM_CTX
                        WB-JEV-003: override the Ollama judge's context window size (num_ctx).
                        Default: rationality.yaml's backend.num_ctx, or Ollama's own default
                        (16384) if that is unset too.
  --rationality-table RATIONALITY_TABLE
                        Path to the persisted rationality table JSON (default:
                        <out>/rationality.json).
  --rationality-max-calls RATIONALITY_MAX_CALLS
                        Cap on judge calls (candidates for noul, chunks for choice) per simulation
                        run; overrides rationality.yaml's max_judge_calls_per_run (default:
                        unlimited).
  --route-rho ROUTE_RHO
                        WB-ROUTE-001 S1: override templates/<genre>/route.yaml's rho (0 disables
                        the route weighting layer; that is the template default). Requesting rho>0
                        for a template with no route.yaml is an error.
  --resume              WB-GA-RESUME: resume from the last generation completed in
                        <out>/ga_state.json instead of starting over.
  --resume-allow-code-change
                        WB-GA-RESUME: with --resume, downgrade an engine_hash/gapengine_hash
                        mismatch to a warning instead of refusing (for an intentional mid-run code
                        change). cfg_fingerprint mismatches -- a different experiment -- are
                        always refused.

    例:

    python scripts/evolve.py --project projects/momotaro_plus2 --template templates/momotaro_plus2 `
  --out C:\WorldBloom-data\runs\my-exp --generations 20 --population 100 --seeds 3

    出力先はリポジトリの外（ローカル）の runs/<experiment>/ に置いてください（詳しくは実行結果のファイル）。

    scripts/synopsize.py — あらすじを生成する¶

    archive.json の各セルからあらすじを生成します。--cells を省略すると全セル、指定すると該当セルだけを更新し他のエントリは保持します。

    usage: synopsize.py [-h] --archive ARCHIVE --runs RUNS --out OUT
                    [--backend {claude-cli,codex-cli,anthropic,openai,ollama,llama-server,none}]
                    [--project PROJECT] [--template TEMPLATE] [--settings SETTINGS]
                    [--cells CELLS [CELLS ...]] [--timeout TIMEOUT]

Generate synopses for all archive elites.

options:
  -h, --help            show this help message and exit
  --archive ARCHIVE
  --runs RUNS
  --out OUT
  --backend {claude-cli,codex-cli,anthropic,openai,ollama,llama-server,none}
  --project PROJECT
  --template TEMPLATE
  --settings SETTINGS
  --cells CELLS [CELLS ...]
                        Only update these archive cell keys; preserve other entries.
  --timeout TIMEOUT

    scripts/narrate.py — 本文を生成する¶

    selection.json で採用したセルだけを本文化します。--synopses を渡すとあらすじの内容をプロンプトに含めます。

    usage: narrate.py [-h] --archive ARCHIVE --selection SELECTION --out OUT [--runs RUNS]
                  [--synopses SYNOPSES]
                  [--backend {claude-cli,codex-cli,anthropic,openai,ollama,llama-server,none}]
                  [--project PROJECT] [--template TEMPLATE] [--settings SETTINGS]
                  [--timeout TIMEOUT]

Narrate human-selected archive elites.

options:
  -h, --help            show this help message and exit
  --archive ARCHIVE
  --selection SELECTION
  --out OUT
  --runs RUNS           Run root; defaults to the archive directory.
  --synopses SYNOPSES   Optional synopses.json used as selection context.
  --backend {claude-cli,codex-cli,anthropic,openai,ollama,llama-server,none}
  --project PROJECT
  --template TEMPLATE
  --settings SETTINGS
  --timeout TIMEOUT

    scripts/random_baseline.py — 無作為基準を測る¶

    方針（遺伝子）を持たない完全無作為な個体だけで、結末への到達率と多様性を測る対照実験です。

    usage: random_baseline.py [-h] --project PROJECT --template TEMPLATE --out OUT [--seeds SEEDS]
                          [--seed-base SEED_BASE]
                          [--target-ending TARGET_ENDING [TARGET_ENDING ...]]

Run a policy-free random-seed baseline.

options:
  -h, --help            show this help message and exit
  --project PROJECT
  --template TEMPLATE
  --out OUT
  --seeds SEEDS
  --seed-base SEED_BASE
  --target-ending TARGET_ENDING [TARGET_ENDING ...]
                        Override target ending ids; any listed ending counts as reached.

    scripts/readable.py — 読者向け要約¶

    generate でLLMによる短い要約を作り、approve でその成果物（sha256付き）を人が承認します。

    usage: readable.py [-h] {generate,approve} ...

One-shot reader-summary generation. No retries and no automatic approval.

positional arguments:
  {generate,approve}

options:
  -h, --help          show this help message and exit

    scripts/world_patch.py — 世界の自己拡張パッチ¶

    propose（提案）・check（追試）・approve/reject（承認・却下）・list/reopen/repair（一覧・差し戻し・修復）のサブコマンドを持ちます。詳しくは世界を作るを参照してください。

    usage: world_patch.py [-h] {propose,check,approve,reject,retire,usage,list,reopen,repair} ...

World-expansion patch proposals, gates, and approval.

positional arguments:
  {propose,check,approve,reject,retire,usage,list,reopen,repair}

options:
  -h, --help            show this help message and exit

    scripts/world_demand.py — 世界拡張の需要レポート（読み取り専用）¶

    実験ディレクトリを読み、空振りが多い場所・行動から不足している要素を報告するだけのCLIです（world_patch.py propose の下敷き）。

    usage: world_demand.py [-h] [--all] [--subject SUBJECT] [--out OUT] [--save] experiment_dir

Read-only "world demand" report CLI (WB-WORLDGROW-001, stage 2). Thin wrapper around
gapengine.world_demand.build_report(): prints a Japanese zone table plus the "拡張トリガー" section
(zones/verbs that whiff almost every time and eat a real share of the story's decisions --
candidates for "the world's content is thin here"). Writes nothing under the experiment directory
unless --save is given.

positional arguments:
  experiment_dir

options:
  -h, --help         show this help message and exit
  --all              scan every layers.jsonl instead of just archive exemplars
  --subject SUBJECT  decision subject to track (default: each file's protagonist)
  --out OUT          also write the JSON report here
  --save             also write <experiment_dir>/world_demand.json (backfill for an existing run)

    scripts/export_static.py — 公開用の静的HTML書き出し¶

    実験結果を読み取り専用の静的サイトとして書き出します（一般公開用）。

    usage: export_static.py [-h] --runs RUNS --out OUT --experiments EXPERIMENTS [EXPERIMENTS ...]

Static HTML export of experiment results for public (read-only) disclosure. Reads run artifacts
under --runs (archive.json/summary.json/synopses.json/ selection.json/stories/) and writes a self-
contained static site under --out: one index.html with a MAP-Elites grid per experiment, plus one
HTML page per selected story. No JS, no external assets. --out is wiped before writing. Never
point it at a gh-pages checkout: that branch also holds the docs site under docs/ (published by
.github/workflows/docs.yml). Export elsewhere, then copy index.html and stories/ over.

options:
  -h, --help            show this help message and exit
  --runs RUNS
  --out OUT
  --experiments EXPERIMENTS [EXPERIMENTS ...]

    scripts/pack_samples.py — ビューア用サンプルの抽出¶

    実験の実行結果から、配布版ビューア（Viewer exe）が読める最小限のサンプル一式だけを別フォルダへコピーします。

    usage: pack_samples.py [-h] --runs RUNS --out OUT --experiments EXPERIMENTS [EXPERIMENTS ...]

Copy minimal viewer-readable samples out of experiment runs.

options:
  -h, --help            show this help message and exit
  --runs RUNS
  --out OUT
  --experiments EXPERIMENTS [EXPERIMENTS ...]

    viewer/server.py — 画面を起動する¶

    --control を付けない既定状態では、書き込み系のAPIはすべて拒否される閲覧専用として動きます（詳しくはHTTP API）。

    usage: server.py [-h] --runs RUNS [--host HOST] [--port PORT] [--control CONTROL] [--repo REPO]

View WorldBloom experiment archives.

options:
  -h, --help         show this help message and exit
  --runs RUNS        Root containing WorldBloom experiment directories.
  --host HOST        Listen address; defaults to loopback only.
  --port PORT
  --control CONTROL  Enable persistent configuration/job APIs at this control root.
  --repo REPO

    例（フル機能で起動）:

    python viewer/server.py --runs C:\WorldBloom-data\runs --control C:\WorldBloom-data\control
