    用語集¶

    WorldBloom の画面と、このドキュメントに出てくる用語をまとめます。画面上のヘルプ（用語にカーソルを合わせたときの説明）と同じ定義です。入力・進化・格子（Sifting）・出口の4つに分けています。

    入力¶

    用語 意味
    世界（world） 地名・経路・日数と登場人物の初期状態の組。projects/<世界> に置く。詳しくは世界を作る
    ジャンル（テンプレート） 世界が使う文法の組。行動グラフ（使える行動と前提）、正典の傾向、効果表、ルール、格子の軸。templates/<ジャンル> に置く
    7層 登場人物の状態モデル。能力・認識・資源・段階（フェーズ）・身分・目的物（対象）・伏線（遅延効果）。行動はこの層を直接読み書きする。詳しくは7層構造
    生命状態（vitality） 生きている（alive）／倒れた（downed）／蘇生した（revived）／死亡（dead）。倒れても味方の救出や自力回復で戻れる
    結末（target ending） 状態に対する条件式。これを満たしたランだけがQD 格子のアーカイブに入る
    正典（canon） そのジャンルで「よくある」行動の傾向。新規性志向の遺伝子が避ける対象であり、前例表の初期値
    伏線（遅延効果） 先に置いた行動が後で効く仕組み。設置と回収の条件を持ち、未回収のまま終わると品質 q が減点される

    進化¶

    用語 意味
    遺伝子（戦略ベクトル） 主人公の方針を表す9個の数値。詳しくは遺伝子（Genome）
    個体 1つの遺伝子。世代ごとに個体数ぶん評価される
    世代 GA の反復回数。世代ごとに個体を評価し、格子を更新する
    seed（種） 乱数の種。同じ遺伝子でも種が違えば世界の初期条件が変わり、別の経緯になる（探偵なら真犯人が変わる）
    ラン 1つの遺伝子×1つの種で世界を走らせた1回。結果は layers.jsonl というログになる
    実験（run） 1回の GA 実行。実行設定（config）1つから生まれ、runs/<実験名> に記録が残る
    到達／到達率 固定した結末に届いたか。到達率はその世代の全ラン（個体数×seed数）のうち届いた割合で、格子に入るためのゲートであり、探索が最大化する対象ではない
    前例表 正典・前世代のアーカイブ・自己履歴から作る「もう見た筋書き」の表。新規性志向の遺伝子が避ける対象
    共進化 敵役にも遺伝子を持たせ、主人公と交互に進化させるモード。既定はオフ
    メタ進化 9つの数値遺伝子に加えて、ルールごとの有効・無効も探索するモード。既定はオフ
    無作為基準 方針を持たない完全無作為な個体だけで結末に届く割合と多様性を測る対照実験（scripts/random_baseline.py）
    決定論 同じ世界・遺伝子・種・前例表・エンジンなら、ログがバイト単位で一致すること。詳しくは決定論
    κ（カッパ、合理性） ジャンルが持つ合理性判定（Jev）の強さ。実行設定で 0〜1 の値を指定する。詳しくは実行設定

    格子（Sifting）¶

    用語 意味
    アーカイブ／格子 到達したランを置く MAP-Elites の格子。各マスに最良の1本だけが残る。詳しくはQD 格子
    セル（マス） 格子の区画。行は主導カテゴリ、列は起伏（volatility、low/mid/high）
    主導カテゴリ そのランで実際に多く効いた行動の種類（I 自己強化、II 認識と伏線、III 関係構築、IV 身分、V 移動と停滞、VI 外部介入）。遺伝子の傾向とは別の値
    起伏（volatility） 主人公の7層の状態がターンごとにどれだけ揺れたかの分散。閾値は世代0の母集団で決めて固定する
    質 q 結末に届いたランの質。目的物の移動、関係の振れ幅、復帰、力関係の逆転、新事実の獲得、信念の反転、前提を揃えた行動の連鎖を数え、空振りを減点する絶対尺度（0〜1）。q̄ はアーカイブ全体の平均
    占有マス アーカイブが埋まった区画の数。多いほど違う種類の物語が見つかっている
    相異度 アーカイブに残ったラン同士がどれだけ違う経路を通ったかの平均。1に近いほど多様
    傾向 その個体の遺伝子がいちばん重みを置く行動カテゴリ。主導カテゴリとは一致しないことがある
    親 その個体を生んだ2つの個体
    系譜（主系） エリートから親を一本道でたどった列。二親のうち遺伝子が近い方だけを採用する
    転機 主系の隣り合う親子を同じ種で再実行し、主人公の決定が最初に分かれた地点
    Sifting 実験が残した候補をふるいにかけ、読む価値のあるものを採用する工程。詳しくはSifting
    選定状態 ✔ 採用（生成に進める）／⏸ 保留／✖ 除外／○ 未分類

    出口¶

    用語 意味
    候補ID 実験・世代・個体・seed の組を一意に指すID。選定と生成はこの単位で記録される
    あらすじ生成（synopsize） 格子の各ランから注目場面を抜き出し、LLM に短いあらすじを書かせる工程
    上映生成（narrate） 採用した候補だけを LLM で長い本文にする工程
    backend / model 本文を生成した方式とモデル名（例: ollama / qwen3.5:9b-q4_K_M）。詳しくはLLM バックエンド
    選択・根拠・代償・転機 候補の詳細に出る4項目。ある選択が、どの信念を根拠に行われ、何を失い、後続の何につながったかをログから機械的に抽出したもの
    世界の自己拡張 GA 実験中に空振りが続いた場所・行動から、足りない要素（場所・品・事実）を提案する仕組み。詳しくは世界を作る
    GPU ガード ローカル LLM（llama-server）と Ollama の GPU 使用を調停し、熱が下がるまで一時待機する仕組み。詳しくはGPU ガード
