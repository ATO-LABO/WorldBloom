# ドキュメントのパス表記

文書中のファイルパスとコマンドは、特に指定がなければWorldBloomリポジトリの直下を基準にしています。コマンドを実行する前に、手元でcloneしたWorldBloomフォルダへ移動してください。

| 表記 | 意味 |
| --- | --- |
| `.`、`docs/`、`scripts/` など | WorldBloomリポジトリの直下、またはその中の相対パス |
| `../WorldBloom-data/` | リポジトリと同じ親フォルダに置く、ローカルデータ保存先の例 |
| `../WorldBloom-data/runs/<experiment>/` | 実験結果の保存先の例。`<experiment>` は実験名に置き換える |
| `../WorldBloom-data/control/` | ジョブ・設定などの制御データの保存先の例 |
| `../StorySim/` | 設計時に参照した別リポジトリの配置例。WorldBloomへの同梱物ではない |
| `C:/path/to/llama-server.exe`、`C:/path/to/*.gguf` | 実行ファイル・モデルの絶対パスの記入例。自分の環境の実際のパスに置き換える |

`../WorldBloom-data/` という名前や配置は必須ではありません。`runs/` と `control/` はリポジトリの外に置き、同期ドライブを避けたローカル保存先を指定してください。空白を含むパスは引用符で囲みます。

設計書・検証記録に残っていたPC固有の絶対パスも、この表記に統一しています。実験名と配下のファイル名は当時の記録を維持しています。これは文書上の表記変更であり、実データの移動や実験の再実行を示すものではありません。過去の検証成果物がすべてリポジトリに含まれているわけではないため、再検証には対応するデータを別途用意してください。
