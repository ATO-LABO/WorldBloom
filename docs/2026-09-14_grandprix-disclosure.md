# WorldBloom 生成プロセス開示文書（第五回AIアートグランプリ D部門）

作品タイトル: 『WorldBloom ── 遺伝的アルゴリズム×LLM による結末固定型の物語生成エンジン』

作成: 2026-09-14。用途: 応募条件「実際に利用したAIモデル・シード値・プロンプト・データセット等、生成プロセスを審査委員会に開示できること」への回答。読み手は審査委員会（技術者とは限らない）。

## 1. 作品の構成と AI の関与

WorldBloom は、物語の**設定と結末を先に固定**し、その間の道のりだけを機械に探させるツールである。工程は四つに分かれ、AI（大規模言語モデル）が関与するのは最後の一つだけである。

| 工程 | 何をするか | AI の関与 |
| --- | --- | --- |
| 1. シミュレーション | 主人公と脇役を七層（力・認識・資源・段階・身分・目的物・伏線）の状態として置き、規則と乱数だけで行動を選び、出来事を `layers.jsonl` に記録する | **不使用** |
| 2. 進化（遺伝的アルゴリズム） | 行動の傾向を表す九つの数値（戦略ベクトル）を遺伝子とし、固定シードで走らせ、結末に届いた個体だけを格子（主導した行動の種類 × 揺れ幅）に残す（MAP-Elites） | **不使用** |
| 3. 選定 | 格子のあらすじを人が読み、本文にする道のりを選ぶ | 人 |
| 4. あらすじ化・本文化 | 選ばれた道のりの出来事列だけを渡し、日本語の文章にする | **使用**（下記モデル） |

主張: 何が起きるかは規則と進化が決め、AI は言葉だけを書く。出来事・勝敗・因果は AI に追加させない（プロンプトで明示的に禁止）。

## 2. 使用ツールとモデル

- シミュレーション・進化・選抜・ビューア: Python 3.13、自作。外部依存は PyYAML のみ。ビューアは標準ライブラリの HTTP サーバー。
- あらすじ・本文の生成（工程 4）:
  - **Qwen3.5 9B（`qwen3.5:9b-q4_K_M`、Apache-2.0）** を **Ollama** でローカル実行（RTX 4070 Laptop 8GB）。思考モード無効（`think: false`）、文脈長 16384、最大出力 4096。温度などは Ollama のモデル既定値。乱数シードは §8 に記載。
  - 恋愛・探偵のあらすじ 15 本は 2026-09-12 に **Codex CLI（GPT-5.6 sol）** で生成したものを使用。本応募で提出する本文と桃太郎のあらすじはすべて Qwen3.5 で生成。
- 実装補助: Claude Code（Fable 5.1／Opus／Sonnet 5）と Codex CLI（GPT-5.6 sol）を設計・実装・レビューに使用。**エンジンの出来事生成に LLM は関与していない。**
- ファインチューニング: 行っていない。学習用データセットなし。

## 3. 世界定義と固定結末（桃太郎）

- 世界: `projects/momotaro/`（主体 7: 桃太郎・犬・猿・キジ・おじいさん・おばあさん・鬼。場所: 村・森・道中・海・鬼ヶ島）。テンプレート: `templates/momotaro/`（行動グラフ・修飾ルール・正典プライア・QD 軸・伏線ライブラリ）。
- 固定結末: `homecoming`（鬼ヶ島の宝物を村へ届ける）。`homecoming_shared`（還元の誓いを立てて分け合う）も到達扱い。
- 死のルール: 通常の敗北は `downed`（介抱・休養で復帰）。死は `lethal` 属性を持つ行為・道具のみ。桃太郎は `lethal_exempt`。
- 伏線ライブラリ: `campfire_oath`（焚き火の約束）、`forest_shortcut`（森の抜け道）、`oni_gap`（鬼の隙）、`village_promise`。設置・回収は行動として記録され、未回収は品質の減点になる。

## 5. 決定論と再現性

- 同じ `(世界, 遺伝子, シード, 前例表)` で `layers.jsonl` はバイト単位で一致する（乱数は単一の `random.Random(seed)`、候補生成と方針は乱数を消費しない、同点は名前順）。回帰テストで固定ハッシュ 2 本を検証。
- テスト: `python -m unittest discover -s tests`、352 件通過（提出版 fdbcef2 で実測）。
- LLM の出力（工程 4）は再現性を保証しない。プロンプトは全件保存しており（`runs/<exp>/prompts/`）、同じプロンプトで再生成できる。

## 6. 格子（QD）と品質

- 縦軸: 主人公の effective な決定の主導カテゴリ（I 力: 修行・仲間・道具・弱体化・犠牲／II 情報: 観測・伏線・ミスリード・露見・転換／III 社交: 試練・説得・誓約・ジェスチャー／IV 身分: 変装・横取り／V 移動と停滞: 越境・追跡・休養・倒れて起きる／VI 外部介入と還元。詳細設計 §7 の行動タイプ表に対応）。横軸: 状態ベクトルの揺れ幅（volatility）を世代 0 の三分位で low/mid/high に固定。
- 品質: 結末到達・前提連鎖の加点・伏線未回収の減点などを合成した絶対スケールの値。
- 桃太郎テンプレートの格子は 6×3=18 マス。

## 7. 実測

| 項目 | 結果 |
| --- | --- |
| 無作為 1000 シード（方針なし） | 結末到達 **7 本**。全ランの主導カテゴリ分布 I 38 / II 6 / III 929 / V 27 |
| 進化 exp12（100×20 世代×3 シード） | 到達率 1.3% → 2.3%、格子 **10 マス**占有、平均品質 0.35、アーカイブ相異度 0.80 |
| 格子に残った道のりの例 | I\|mid 力押し（fight 4 回）／III\|high 鬼に偽の弱点を吹き込み金棒を封じる／I\|low 宝を盗んだ罪を三度突きつけて勝つ／V\|mid 犬・桃太郎・キジが倒れ、妨害と金棒封じで立て直す |
| 恋愛（exp7、`0b67e7c`） | 到達率 7% → 33%、6 マス |
| 探偵（exp10、`fed6acf`） | 到達率 6% → 20%、9/9 マス。誤認 → 再考 → 正解の告発が 1 件 |

## 8. あらすじ・本文のプロンプト

- あらすじ: `gapengine/synopsis.py` が場面抽出（主人公の effective 決定と転機）を日本語の箇条書きに変換し、「200〜300 字、結末を明かす、ログにない人物・勝敗・所持品・因果を追加しない、本文のみ出力」を指示する。実物: `runs/exp12-momotaro/prompts/synopsis-*.txt`（10 本）。
- 本文: 同じ場面抽出にあらすじを添え、本文のみを出力させる。実物: `runs/exp12-momotaro/prompts/narration-*.txt`（3 本）。
- 生成条件: Qwen3.5 9B Q4_K_M、think 無効、num_ctx 16384、num_predict 4096、温度等はモデル既定。桃太郎 3 本・探偵 1 本は試行 1 回（乱数シード指定なし）。恋愛 1 本は 2 回連続で出力が止まらず上限到達（`done_reason: length`）となったため失敗として記録し、3 回目に Ollama の `seed: 7` を指定して生成した本文を採用した。失敗 2 回はツールが記録した事実であり、本文の手直しはしていない。
- 付録 A（あらすじプロンプト 1 本の実物）、付録 B（本文プロンプト 1 本の実物）、付録 C（生成された本文 1 本）を末尾に添付。同じものは `samples/exp12-momotaro/` にも入っている。

## 9. 限界（公正のため明記）

- 9B の量子化モデルのため、本文に機構の語（「強さが上昇」「感情値」）が漏れることがある。本応募では手直しせず、生成のまま提出する。
- LLM 出力は再現性が限定的。出来事の層（工程 1〜2）は完全に再現できる。
- 到達率の絶対値は低い（2.3%）。これは結末を「宝を持って帰る」に固定した世界の厳しさそのものであり、格子に多様な道のりが残ることを重視した。
- 共進化（敵役側の同時進化）は機構として実装済みだが、本応募の桃太郎実験では OFF。
- 未解決の設計論点は詳細設計書 §20.2 に列挙している。
