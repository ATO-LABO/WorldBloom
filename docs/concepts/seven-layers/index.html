    7層構造¶

    WorldBloom の登場人物は、台詞や性格の文章ではなく、実行時にそのまま保持する7つの層の数値・集合として表されます。行動（動詞）はこの層を直接読み書きし、layers.jsonl に書かれるログはその差分です。射影や中間レイヤーは無く、この7層が判定の唯一の状態です。

    層 中身 物語での役割
    1. 能力層 真の基礎値 base と、道具・味方・事実による修飾値 modifiers 勝負の勝ち負けを決める。修行で上がり、弱体化で下がる
    2. 認識層 相手の力についての信念 beliefs_about、知っている事実 knowledge 「金棒を知らずに挑んで負ける」を生む。認識のずれが物語を動かす
    3. 資源層 持ち物 inventory、評判 reputation、引き出せる関係資本（bonds） 犠牲や交渉の元手
    4. フェーズ層 通過した閾値 phase（不可逆）、使える行動 verbs 鬼ヶ島に渡ると戻れない、渡って初めて使える行動がある
    5. 身分層 本当の身分 identity_true と、見せている身分 identity_displayed 変装、偽主人公、露見
    6. 対象層 誰が何を狙い（goal）、今誰が持っているか（world.objectives） 宝の奪い合い。所有の移転と勝敗は別に扱う
    7. 遅延効果層 仕込まれた伏線（world.pending_effects）と、その回収条件 先に置いた行動が後で効く。未回収の伏線は品質の減点対象

    これに加えて生命状態（vitality）を持ちます。alive（生きている）→ downed（倒れた）→ revived（蘇生した）／dead（死亡）と遷移し、倒れても味方の救出や自力回復で revived に戻れます。死亡するのは、勝者側の行為や道具が lethal を持つときに限られます。これにより「疑似的な死と再生」が物語の一部として自然に現れます。

    身分層（identity）¶

    identity_true（本当の身分）と identity_displayed（見せている身分）を分けて持ちます。disguise 行動でこの2つが乖離すると変装になり、observe の積み重ねや confront によって identity_seen（露見済み）が立つまでは、他の登場人物はこの人物を identity_displayed の名前でしか扱えません。関係行列・敵対判定・行動候補の役割プライアは、露見済みなら真の身分、そうでなければ見せている身分で引かれます（perceived_name）。露見の瞬間、相手からの stance は真の身分に対する値へ切り替わるため、正体を明かす場面が物語上の転換点として機能します。世界のテンプレートは、変装中の身分に対する初期関係（例: 「旅の商人」への affinity）をあらかじめ書けます。

    フェーズ層（phase）¶

    phase は、その人物が通過した不可逆な閾値の集合です（例: 「越境」）。世界のテンプレートは phase_rules で「どのゾーンに入ると、どの閾値を通過し、どの行動が使えるようになる／使えなくなるか」を宣言します。通過は取り消せないため、「鬼ヶ島に渡ったらもう村には戻れない、その代わり鬼ヶ島でしかできない行動ができる」といった不可逆な進行が生まれます。実際に選べる行動（availableActions）は、その人物が持つ動詞のうち、行動タイプの前提条件を満たし、かつ現在の phase で無効化されていないものの積集合です。

    対象層（target）と所有の移転¶

    「誰が何を狙っているか」（goal）と「今その目的物を誰が持っているか」（world.objectives 上の所持者）を分けて持ちます。この分離により、所有の移転と勝負の勝敗は別の出来事として扱われます。目的物は戦って奪うだけでなく、negotiate（要求する側）と concede（持っている側が譲る側）のやり取りでも移転でき、関係が十分に良ければ戦わずに、そうでなくても資産の交換（取引）が成立すれば移転できます。concede は所有の移転であると同時に和解でもあり、成立すると双方の敵対関係が解除されて、譲渡した直後にまた戦いを仕掛けられることはありません。桃太郎の結末「宝を村へ」は、鬼を倒さなくても、この交渉ルートで到達できます（同じ結末への別の道のり）。

    資源層（resource）¶

    持ち物 inventory、評判 reputation、引き出せる関係資本（bonds）の3つです。sacrifice（犠牲）や grand_gesture（大きな贈り物や公開の行為）は、資産や bonds を消費して能力の修飾値や身分の通過条件を得る手段になります。評判は donate（還元）で上がり、pledge（誓約）を破ると大きく下がり、grand_gesture は公開の行為であるため成否によって上下どちらにも動きます。

    生命状態（vitality）の遷移¶

    alive の人物が非致死的な行為に敗れると downed（倒れた）になります。倒れている間に選べる行動は rest だけですが、一定ターンが経つと自動で revived に回復するか、同席する味方の rescue（救出）行動によって即座に回復できます。自動回復までのターン数は、その場にいる味方のうち stance が一定の閾値以上の人数だけ短くなります（個々の関係の強さの度合いではなく、閾値を満たす味方の頭数が効きます）。dead（死亡）になるのは、勝者側の行為や道具に lethal（致死）が付いているときの lethal_chance によってのみで、通常の敗北では倒れるだけです。テンプレート側で lethal_exempt に指定した人物は、致死的な行為からも守られます（ジャンルの約束事であって、エンジンが結末に誘導しているわけではありません）。この仕組みにより、「倒れてから仲間に救われて逆転する」という高い起伏の展開が、特別なイベントとしてではなく通常のルールから生まれます。

    関係行列（stance / bonds）¶

    登場人物どうしの関係は world.relations[a][b] = {affinity, awareness} という1つの行列で表します。stance(a, b) は「a が b をどう見ているか」（affinity をそのまま読む向き）、bonds(a) は「a が引き出せる関係資本」（他者からの affinity の正の部分の合計）です。同じ行列を双方向に読むだけで、資源層の bonds と関係性の stance を二重に持ちません。

    勝負の解決は「差分ゲーム」¶

    勝負は、両者の真の強さの差にロジスティック関数を掛けた確率で判定します（乱数を1回だけ消費）。ここで重要なのは、行動を決める側は「信じている強さ」（認識層）を使い、実際の勝敗は「真の強さ」（能力層）で決まるという非対称性です。金棒（visible: false の修飾値）を知らない桃太郎は、80対90で優勢だと信じて挑み、真の値120に負ける——この認識のずれこそが物語を駆動する仕組みです。

    述語（結末・伏線条件・ルールが共有する語彙）¶

    結末の判定式、伏線の回収条件、行動の変調ルールは、すべて同じ述語の名前空間を共有します。代表的なものに holds(a, item)（所持）、zone(a)（居場所）、stance(a, b)（関係性）、vitality(a)（生命状態）、believed_strength(a, b)（a から見た b の信じている強さ）などがあります。桃太郎の結末は次のように書けます。

    ending:
  - id: homecoming
    when: "holds(桃太郎, 鬼ヶ島の宝物) and zone(桃太郎) == '村'"
    label: 鬼退治を果たし、宝を村へ持ち帰った

    この語彙は LLM へのあらすじプロンプトにも同じ辞書として渡されます。

    出来事の生成に LLM は関与しない¶

    各ターン、主人公はその場で可能な行動候補を列挙し、基礎の重み（気質と世界の状態）に遺伝子の乗数を掛けて1回だけ抽選します。行動の前提（観測してから無力化する、など）を満たさない候補はそもそも候補に並ばないため、因果の一貫性は構築的に保証されます。ここに LLM は一切入らず、出来事の列は純粋にシミュレーションの結果です。同じ世界・同じ遺伝子・同じ乱数の種なら、ログはバイト単位で一致します（詳しくは決定論）。
