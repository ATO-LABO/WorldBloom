## 仕様と変更範囲

`engine/world.py` に明示設定の読み込み、`engine/sim.py` に有効化した世界だけの実行・候補 hook を追加。
`engine/slot_runtime.py` が実際の native Subject の位置・所持品・knowledge と runtime の活動状態を更新する。
ログの後加工で準備完了や在場を作らない。実行結果を `action_completed` と `activity_snapshot` に記録する。
既存の VerbEngine、Linux/UI/job管理、gapengine/汎用経路探索は変更しない。別ブランチはマージしていない。

明示設定は `slot_execution: {mode: cultural_festival_next_boundary_v1, contract: contract_v1.yaml}`。
設定がない従来世界は既存の Simulation.run / candidates をそのまま使う。コード由来の engine_hash は変更される。
この mode は文化祭契約 v1・1日・1枠行動用の限定実装。戦闘、確率効果、phase rules、未知の scheduled effects を無視せず拒否する。
UIへの設定入力、他世界への汎用化は今回の範囲外。

各境界では前枠の完了→予定イベント→同室観測/各人の知識記録→15時 primary→次行動を選択。
17時は完了・観測だけで新しい行動は始めない。移動候補は隣接1辺に限定。開門は前報の通行フラグを維持し、8時から移動を選択できる。
行動の開始時には所要1枠と完了 tick が確定・ログ化される。衣装準備で蒼の実 inventory に衣装を加える。
練習回数・音響確認・展示協力の回数は活動状態に保持。展示協力の回数を展示完成と同一視しない。

相談/依頼/了承/断りは dialogue の intent として実装。依頼が相手に届くのは次枠の完了時点。
了承/断りの候補は本人に届いた未回答の依頼に対してだけ生成される。同室での発言は、その行動場面に同室だった人物へ完了時に伝わる。
宛先指定の contact は送信者と受信者にだけ伝わる。移動中の他者を追跡する情報を全員へ配信しない。
位置・活動の全体スナップショットは検証者用。人物側の観測は自室の在場者、場面内で見聞きした行動・発言、自分の選択と自分宛の連絡だけ。
人物の複数目的は固定した人物 YAML を保持し、サンプル Policy の選択理由に反映する。一般目的の自動理解・任意の legacy Policy への接続は提供しない。

共同運搬2枠/合意後の中断は今回も未対応として候補から除外。ユーザー承認された1枠限定の初回試走を維持。
15分間の本公演内部の演技は模擬実装しない。primary は在場、準備状態と出演の了承/断りは別フィールド。
出演了承があっても演技そのものの実行成功とは断定しない。

## 小規模探索と4ログ×4視点

探索は8 seed のみ。全員の性格・目的・初期位置・初期知識を維持。変えるのは蒼が13時30分〜14時30分に選ぶ合法な移動/展示協力/相談/了承だけ。
選択重みは全 run 同一の固定 traits から算出し、seed は行動選択だけを変える。相手の秘匿位置・内心で行動を選ばない。
探索ループで world/subject を改変しない。各 run は同じ設定から新たに native 実行する。

8結果は15時在場7本、15時30分到着1本。
行動列の fingerprint が初めて異なる4本を選び、seed [0, 1, 4, 7] を採用。結末や分類の quota は使わない。
分類は在場/遅刻の実測とログに記録した選択理由を確認した後に行う。『来られない』『行きたくない』を必ず出すことは要求しない。
遅刻ログは展示側の行動を続けた後の遅れで、世界が物理的に閉鎖されたと捏造しない。

各採用ログに4人の `knowledge-人物.json` と `view-人物.md` を用意。合計16視点。
視点別記録作品は実際の個人観測だけから決定的に文章化した初稿で、LLMは使用していない。
他人の内心や他室の行動を文章へ補わない。文学的な推敲や本公演内部の描写は未実施。
