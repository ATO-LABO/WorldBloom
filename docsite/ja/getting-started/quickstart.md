# クイックスタート（桃太郎で一周）

Studio 版（または `--control` 付きで起動したソース版）で、桃太郎の世界を最初から最後まで一周します。

## 1. 世界を選ぶ

起動すると「**世界を選ぶ**」画面（ホーム）が開きます。同梱の「**桃太郎**」の世界をクリックします（「桃太郎＋」「桃太郎＋2」は拡張版です）。新しく作る場合は「**＋ 新しい世界を作る**」から名前と概要を入力します。

## 2. 実行設定

「**実行設定**」画面（見出しの下に「探索する条件を決める」と表示）で、世代数・個体数・シード数などの探索規模と、実行時間の上限を決めます。「**保存して実行条件へ →**」で次に進みます。

## 3. 実行

設定を確認して実行を開始すると、進捗（世代・完了個体数・残り時間の目安）が表示されます。GA 実験そのものは LLM を使わないため、この段階では文章生成の設定は不要です。

## 4. 結果（QD 地図）と Sifting

実行が終わると、主導カテゴリ×volatility の格子（QD 地図）が表示されます。マスをクリックすると候補の詳細が開き、「**物語**」「**選択とメモ**」「**実験データ**」の3タブで内容を確認できます。気に入った候補を採用すると、下部の「**採用候補を確認（N件） →**」ボタンが押せるようになります。

## 5. あらすじ・本文生成（任意、LLM 必須）

採用した候補を確認する画面から生成に進むと、「**生成内容を確認**」というダイアログが開き、「**生成を開始**」で実行します。事前に ⚙ 設定で LLM の接続先とモデルを選んでいない場合はここで失敗するので、先に [LLM バックエンド](../usage/llm-backends.md) を設定してください。この工程は省略できます（格子とあらすじだけを見る使い方でも成立します）。

## ソースから CLI で回す場合

画面を使わず、コマンドラインだけで一周する例です。

```
python scripts/evolve.py --project projects/momotaro --template templates/momotaro \
  --out <出力先>/exp1 --generations 20 --population 100 --seeds 3 --keep reached --processes 4
```

**実測値**: 小さめの規模（`--generations 5 --population 30 --seeds 2 --processes 8`、シミュレーション数 = 5×30×2 = 300 件）で 37 秒、QD 地図に 3 マスの候補が残りました（2026-09-25、開発機で計測）。規模を小さくしすぎると候補が 1 つも残らないことがあります。所要時間は世代数×個体数×シード数にほぼ比例します。

あらすじ・本文の生成まで CLI で行う手順は [CLI での作業手順](../usage/cli-workflow.md) を参照してください。
