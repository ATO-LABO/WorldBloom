# クイックスタート（桃太郎で一周）

ここでは `--control` 付きで起動した現行ソース版で、桃太郎の世界を最初から最後まで一周します。Windows配布版Studioの画面と同梱サンプルは、各Releaseの内容に従ってください。

## 1. 世界を選ぶ

起動後の「**今日は何を進めますか**」で「**物語制作**」を選ぶと、「**世界を選ぶ**」画面へ進みます。同梱の「**桃太郎＋3（新形式）**」を開きます（`projects/momotaro_plus3_new`）。新規作成は「**新しい世界を作成**」から[3段階の下書き作成](../usage/create-world.md)へ進みます。既存世界のカードには概要・人物数・場所数・期間・役割が表示されます。

## 2. 実行設定

世界設定を確認し、下部の「**実行条件を決める →**」から進みます。不足項目がある場合は先に設定します。

「**実行設定**」画面（見出しの下に「探索する条件を決める」と表示）で、世代数・個体数・シード数などの探索規模と、実行時間の上限を決めます。「**保存して実行条件へ →**」で次に進みます。

## 3. 実行

設定を確認して実行を開始すると、進捗（世代・完了個体数・残り時間の目安）が表示されます。κ=0なら合理性のAI判定は行いません。κ>0で実行する場合は選択した判定器（OllamaまたはJev）の接続が必要です。あらすじ・本文生成とは別の設定です。

## 4. 結果（QD 地図）と Sifting

実行が終わると、主導カテゴリ×volatility の格子（QD 地図）が表示されます。マスをクリックすると候補の詳細が開き、「**物語**」「**行動ログ**」「**選択とメモ**」「**実験データ**」の4タブで内容を確認できます。気に入った候補を採用すると、下部の「**採用候補を確認（N件） →**」ボタンが押せるようになります。

## 5. あらすじ・本文生成（任意、LLM 必須）

採用した候補を確認する画面から生成に進むと、「**生成内容を確認**」というダイアログが開き、「**生成を開始**」で実行します。事前に ⚙ 全体設定 → AIの設定で保存済みの生成先を確認してください。Gemma 4の選択・保存は画面で行い、他モデルは [LLM バックエンド](../usage/llm-backends.md) の手順で設定します。この工程は省略できます（格子や保存済みの行動ログを読むだけでも利用できます）。

## ソースから CLI で回す場合

画面を使わず、コマンドラインだけで一周する例です。

```
python scripts/evolve.py --project projects/momotaro_plus3_new --template templates/momotaro_plus3 \
  --out <出力先>/exp1 --generations 20 --population 100 --seeds 3 --keep reached --processes 4
```

**過去の実測値（上の新形式の実行時間を保証するものではありません）**: 小さめの規模（`--generations 5 --population 30 --seeds 2 --processes 8`、シミュレーション数 = 5×30×2 = 300 件）で 37 秒、QD 地図に 3 マスの候補が残りました（2026-09-25、開発機で計測）。規模を小さくしすぎると候補が 1 つも残らないことがあります。所要時間は世代数×個体数×シード数にほぼ比例します。

あらすじ・本文の生成まで CLI で行う手順は [CLI での作業手順](../usage/cli-workflow.md) を参照してください。
