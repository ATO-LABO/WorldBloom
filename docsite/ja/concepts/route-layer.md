# 道筋層（寄り道に理由を持たせる）

主人公は基本的に、結末へいちばん近い道筋をまっすぐ進みます。そこから外れる行動（寄り道）には、本来なら何か原因があるはずです——身体の都合、情報不足、思い込み、心情。**道筋層**は、GA が生成した主人公の各決定を「結末に対してどんな意味を持つ行動だったか」で分類し、理由のない寄り道を重み ρ で抑え、理由のある寄り道には動機表で理由を与える仕組みです。7層そのものは変更せず、[Policy](genome.md) が候補の重みを決める際の、もう1つの乗数として働きます。

対応テンプレートは `route.yaml` を持つジャンルだけです。現在は桃太郎＋2（`momotaro_plus2`）のみで、それ以外のジャンルでは道筋層は存在せず、画面にも出ません。

## 行動の分類

主人公の決定1つひとつは、「結末までの最短の計画」と照らして次のいずれかに分類されます。分類自体は常に行われ（測定のみのモード、ρ=0）、あとで説明の理由バッジとしても使われます。

| 分類 | 意味 |
|---|---|
| 前進 | 計画中の道筋を実際に進める行動 |
| 準備 | 最善ではないが筋の通った選択肢（別ルートの下準備、仲間の勧誘など）を進める行動 |
| 寄り道〈身体〉 | 疲労・負傷など、本人の身体の都合による行動（休息など）。罰はしない |
| 寄り道〈手探り〉 | まだ知らないことを探る行動（調査・観察など） |
| 寄り道〈思い込み〉 | 本人が誤って信じている情報に基づく行動。本人の中では筋が通っている |
| 寄り道〈動機〉 | 下記の動機表に一致した行動。動機の強さ（遺伝子）に応じて扱いが変わる |
| 寄り道〈理由なし〉 | 上のどれにも当てはまらない、計画から外れた行動 |
| 見通しなし | そもそも結末までの計画が立たない状態（h が無限大）。道筋層は何も判定しない |

「本人の知識だけで判断する」のが前提です。世界の裏の真実（`world.truth`）は一切読まず、本人が知っている・信じている情報（対象の所在、関係、信じている強さなど）だけを使います。裏で誰が何を持っているかを知らないのに、それを見透かしたかのように動く、ということは起きません。

## 重み ρ（寄り道をどれだけ抑えるか）

分類そのものは判定だけで、実際に候補の重みを変えるかどうかは ρ（0〜1）で決めます。分類ごとの基礎倍率 b を ρ 乗した `m_route = b ** ρ` が、[遺伝子](genome.md)由来の他の乗数（m_cat・m_risk・m_stance・m_nov、κ を使うジャンルでは m_rat も）と掛け合わされて最終的な重みになります。

| 分類 | 基礎倍率 b | ρ=1 での意味 |
|---|---|---|
| 前進 | 1.0 | 変化なし |
| 準備 | 0.5 | 半分に抑える |
| 寄り道〈身体〉 | 1.0 | 罰しない（身体の都合はいつでも正当） |
| 寄り道〈思い込み〉 | 1.0 | 罰しない（本人の中では筋が通った計画を進めている） |
| 寄り道〈手探り〉 | 0.5 | 半分に抑える |
| 寄り道〈理由なし〉 | 0.02 | ほぼ選ばれなくなる |
| 見通しなし | 1.0 | 判定なし（道筋層が何も言えない状態） |

ρ=0（既定）では `b ** 0 = 1.0` となり、どの分類でも重みは変わりません。つまり道筋層は「測定はするが、何も変えない」状態で、既存の実行結果とバイト単位で一致します。ρ を上げるほど、理由のない寄り道が選ばれにくくなります。実行設定の画面では[実行設定の「05. 道筋」](../usage/run-settings.md#05)から指定します。

## 動機表（motives.yaml）——理由のある寄り道

「寄り道〈理由なし〉」になるはずだった候補だけが、動機表と照合されます（前進・準備・身体・思い込み・手探り・見通しなしの行動は動機表の対象外です）。動機表はジャンルごとに `templates/<ジャンル>/motives.yaml` に置く、優先順位付きの規則の並びで、上から見て最初に一致した1件が採用されます。

桃太郎＋2 に定義されている5つの動機:

| 動機 | 条件（例） | 対象の行動 | 効く遺伝子 |
|---|---|---|---|
| 仲間思い | 相手への好感度が高い | 譲渡・情報共有・説得・誓約 | 関係構築（カテゴリIII）の重み |
| 向こう見ず | 勝ち目の薄い相手にそれでも挑む | 対決・妨害・無効化・その区域への移動 | リスク許容度 |
| 恨み | 相手への好感度が低い | 対決・妨害・誘導 | 関係を動かす向き（下げる方向ほど強い） |
| 好奇心 | いつでも | 調査・観察 | 新規性志向 |
| 慎重 | 自分が相手より弱いと信じている | 休息・撤退 | リスク許容度（低いほど強い） |

各行は「対象・条件・動機の理由文」を持ち、たとえば向こう見ずなら「勝ち目が薄いと知りながら、{対象}に立ち向かわずにいられなかった」という理由文が記録されます。

### 遺伝子の強さが選ばれやすさを変える

動機に一致した寄り道は、身体・思い込みのように無条件で罰なし（b=1.0）にはなりません。代わりに、動機ごとに指定された遺伝子の強さ `gene_s`（0〜1）に応じて基礎倍率が連続的に変わります。

```
base = delta + (1 - delta) * gene_s   （delta は「理由なし」の倍率 0.02）
m_route = base ** rho
```

その遺伝子への傾きが弱い個体（gene_s=0）では、動機に一致していても「理由なし」とほぼ同じ扱いになります。傾きが強い個体（gene_s=1）では、身体・思い込みと同じ b=1.0（罰なし）まで扱いが上がります。「動機表に載っている」だけでは自由に寄り道できるわけではなく、その動機に見合うだけ遺伝子が強くなければ、その寄り道はやはり抑えられます。

## 遺伝子による経路選び（gene_affinity）

`route.yaml` の `gene_affinity`（既定 0）と `route_category`（例: 対決=カテゴリI、交渉=カテゴリIII）を設定すると、目的物の持ち主から奪う手段が複数ある局面（対決 vs 交渉など）で、どちらを「最善の計画」とみなすかが個体の遺伝子（対応するカテゴリの重み）でわずかに傾きます。`gene_affinity=0`（既定）では常にコストが低い方を最善とみなし、これは ρ 抜きの計測と同じです。値を上げるほど、対応するカテゴリの重みが強い個体ほどその経路を「最善」と見なしやすくなります（記録される h 自体は素のままで、最善経路の選択にだけ影響します）。

## あらすじ・本文生成への反映

寄り道〈動機〉・〈思い込み〉・〈身体〉・〈手探り〉の理由文は、あらすじ・本文を書く LLM へのプロンプトに「行動の理由」として渡ります（生成プロンプト自身が「理由が記録されていない行動に、ログにない動機を創作しない」よう指示されます）。画面上では、[結果を読む](../usage/read-results.md)のタイムライン・四項目パネル・セルページ冒頭の内訳として、同じ理由文が表示されます。
