# 全体の流れ

WorldBloom が1つの物語を作るまでの流れは、次の5段です。それぞれ詳しい説明ページを持つので、ここでは全体の見取り図だけを示します。

| 段 | やること | 誰が/何が行うか | 詳しくは |
|---|---|---|---|
| 1. 設定と結末を固定する | 地名・経路・登場人物の初期状態（世界）と、そこで使えるジャンルの文法（テンプレート）を用意し、目指す[結末](fixed-ending.md)を先に決める | 人（世界を作る） | [世界を作る](../usage/create-world.md)・[結末固定](fixed-ending.md) |
| 2. 遺伝子を持つ主人公でシミュレーションする | 主人公は「戦略ベクトル」（[遺伝子](genome.md)、9個の数値）を持ち、[7層構造](seven-layers.md)で表された世界の状態から、その都度候補行動を選ぶ。これを固定シードの集合で何百体・何世代も走らせる | GA（遺伝的アルゴリズム）とシミュレーション。LLM は関与しない | [遺伝子（Genome）](genome.md)・[決定論](determinism.md) |
| 3. 結末に到達したランだけを格子に残す | 固定結末に届いたランだけを、質と多様性を両立させる[QD 格子](qd-map.md)（主導カテゴリ×起伏）に、各マス最良の1本だけ残す | GA の評価ループ | [QD 格子](qd-map.md) |
| 4. 人が選ぶ | 格子に残った候補のあらすじ・根拠を人が読み、本文化する価値があるものを選ぶ（[Sifting](sifting.md)） | 人 | [Sifting](sifting.md) |
| 5. LLM が本文化する | 選ばれた候補だけ、LLM があらすじ・本文の文章を作る。出来事そのものは書き換えない | LLM | [文章を生成する](../usage/generate-text.md)・[LLM バックエンド](../usage/llm-backends.md) |

## 押さえておきたい3点

- **出来事の生成に LLM は関与しません。** 行動候補の列挙も、遺伝子による重み付けも、実際にどの行動が選ばれるかも、すべてシミュレーションとその乱数だけで決まります（詳しくは[7層構造](seven-layers.md#no-llm-in-simulation)）。LLM が触れるのは、格子に残った出来事の列を人が選んだあとの文章化だけです。
- **進化させているのは行動の並びではなく、方針（遺伝子）です。** 主人公は9個の数値だけを世代ごとに交叉・突然変異させます。実際の行動は、その方針と世界の状態から都度選ばれます。
- **面白いかどうかを判断するのは常に人です。** GA は「結末に届いたか」「質と多様性」までしか見ません。どの候補を本文化するかは、Sifting の画面で人が決めます。
