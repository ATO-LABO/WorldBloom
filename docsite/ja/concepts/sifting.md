# Sifting

Sifting（ふるい分け）は、[QD 格子](qd-map.md)に残った候補を人が読み、あらすじ・本文にする価値があるかを選ぶ工程です。WorldBloom で「面白いかどうか」を判断するのは常に人であり、LLM ではありません（LLM の役割は選ばれた道のりを文章にすることだけです）。

## 画面の構成

格子のセルをクリックすると、候補の詳細が3つのタブで開きます。

- **物語**: この候補のあらすじ（生成済みの場合）、結末、詳しい根拠・生成状況へのリンク
- **選択とメモ**: 選定状態と自由記述のメモ
- **実験データ**: 候補ID・世代・個体・seed などの実験データ、原記録（`layers.jsonl`）へのリンク

## 選定状態

候補には次の4つの状態のいずれかを付けます。

| 状態 | 意味 |
|---|---|
| ✔ 採用 | 生成に進める |
| ⏸ 保留 | あとで決める |
| ✖ 除外 | 使わない |
| ○ 未分類 | まだ判断していない（既定） |

採用した候補だけが、次の[あらすじ・本文の生成](../usage/generate-text.md)の対象になります。保留にした候補はあとから見直して採用に切り替えられます。選定状態とメモは「選定版」として保存され、他のタブ・実行から先に保存されていると版が進み、あとからの保存は拒否されます（上書き防止のため、保存前に最新の状態を読み直す必要があります）。

## 比較・系譜・転機 { #compare-lineage-turning }

異なる区画の代表候補を2〜4件選んで並べると、比較画面が開きます。あらすじ・「選択・根拠・代償・転機」・実験データ（候補ID・区画・世代・seed・品質・結末・原記録）の3タブで読み比べられます。また、ある候補がどの世代のどの親から生まれたかを一本道でたどる**系譜（主系）**と、隣り合う親子を同じ乱数の種で再実行して主人公の決定が最初に分かれた地点を示す**転機**の可視化もあります。「なぜこの物語になったか」を進化の履歴として確認したいときに使います。
