# 遺伝子（Genome）

主人公（共進化時は敵役も）は「戦略ベクトル」と呼ばれる9個のスカラー値の遺伝子（Policy）を持ちます。これは具体的な行動の並びではなく、行動選択の候補重みを変調するパラメータです。カテゴリ別の重み・リスク許容度・stance（関係性）を動かす向き・新規性への駆動力などが含まれます。中立な遺伝子（重み等分・risk 0.5・bias 0・novelty 0）は無変調（policy なしの実行とバイト一致）で、これが決定論の回帰の錨になっています。

遺伝子の詳しい定義は ATOM-BOX の [なぜ GA と LLM を組み合わせるのか](https://www.atom-box.jp/worldbloom/ga-and-llm/) を参照してください。
