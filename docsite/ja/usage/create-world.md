# 世界を作る

「世界」は、GA 実験の元になる舞台設定（人物・場所・時間・目標の結末）一式です。この画面で作った世界を使って、[実行設定](run-settings.md)から GA 実験を回します。

## 新しい世界を作る

ホーム画面（**世界を選ぶ**）の **＋ 新しい世界を作る** から開きます。

作成方法は3通りから選びます。

- **新しく作る**: 空の世界から始めます。ジャンルは共通の基本ルール（`basic`）が初期値になり、あとから変更できます。
- **既存の世界から作る**: 一覧から作成元の世界を選び、その世界の設定をコピーします。作成元の世界自体は変わりません。コピー時はジャンルも一覧（検索ボックス付き）から選び直せます。
- **ZIPから取り込む**: AI（Codex・Claude Code・Gemini など）に作らせた `world.yaml`・`subjects/*.yaml` 一式をZIPで取り込みます。詳しくは[世界を ZIP から取り込む](import-world.md)を参照してください。

共通の入力項目:

- **世界の名前**（必須、120文字まで。「ZIPから取り込む」のときだけ空欄可 — 空欄ならZIPの `world.yaml` の `name` を使います）
- **世界の概要**（任意、8000文字まで。「新しく作る」のときだけ入力欄が出ます）
- **詳細設定**を開くと **世界ID** が編集できます。半角英数字・ハイフン・アンダースコアのみ（1〜96文字）で、既定では `world-` に続けてランダムな12文字が自動入力されます

作成すると、その世界の**世界設定画面**（次項）に進みます。人物・場所・初期物語はこの時点では空で、あとから設定します。

## 世界設定画面（世界ごとのタブ） { #world-settings }

世界を開く（またはホームの世界カードから「世界を開く」）と、次の5つのタブで設定を確認・編集します。

| タブ | 内容 |
|---|---|
| 世界の概要 | 名前・概要の編集。ジャンルが未設定の世界はここから選べます（[ZIPから取り込む](import-world.md)で作った世界など）。世界の自己拡張（下記）で承認済み・提案中の変更点があれば、ここに表示されます |
| 登場人物 | 人物ごとのパラメータ（9指標）や初期位置などを確認・編集。**人物関係図**（下記）もここから開きます |
| 場所 | 場所（ゾーン）の一覧と、場所どうしのつながり |
| 初期物語 | 導入文（開始時点の状況）の編集 |
| 時間 | 実行日数・1日の時間帯の区切り。**予定イベント**（下記）の確認・編集もここで行います |

道筋層（`route.yaml`）を持つジャンルの世界では、世界画面のサイドバーから「最短経路を調査」（結末までの段取りの一例を最大3本表示する読み取り専用の機能）を開けます。詳しくは[道筋層](../concepts/route-layer.md#route-paths-survey)を参照してください。

編集は項目ごとに保存できます。保存しても、その世界で**過去に実行した結果は変わりません**（次回以降の実行から新しい設定が使われます）。

画面下部のフッターには、未設定の項目（登場人物・場所・主人公・敵役・目標の結末・人物の初期位置のいずれか）があれば「未設定の項目を確認 →」、すべて揃っていれば「実行条件を決める →」（[実行設定](run-settings.md)へ）のボタンが出ます。

閲覧専用の Viewer では、この画面は表示のみで保存ボタンは機能しません（Studio でのみ編集できます）。

## 詳細設定・設定ファイルの編集窓口 { #advanced-settings }

世界設定画面の左メニュー下にある「詳細設定・設定ファイル ↗」から、より踏み込んだ編集に進めます。4つの区画があります。

- **役割と結末**: 主人公・敵役などの役割、目標の結末の設定
- **状況ごとの定石**: ジャンルが持つ定石（何がどんな状況で起きやすいか）を、この世界の人物に当てはめて確認
- **行動図鑑**: 人物が選べる行動の一覧
- **設定ファイル**: 世界フォルダ内の YAML ファイルを直接編集

テンプレート（ジャンル）自体の編集は、ホームの「ジャンル」タブ→ジャンルを開く、または「＋ 新しいジャンルを作る」から行います。ジャンルは複数の世界で共有される、行動とその結果を決める共通ルールです。既存のジャンルは「複製して編集」で複製してから変更できます（元のジャンルを使っている他の世界には影響しません）。

## 人物関係図 { #relationship-workspace }

「登場人物」タブの表示を「相関図」に切り替えると、人物どうしの関係を有向グラフとして確認できます。人物は所属（`affiliation`。未設定なら初期の居場所）ごとに色分けされ、主人公の所属を起点にグループが並びます。

- **表示範囲**: 「全体」（登場人物すべて）と「人物フォーカス」（1人を選び、直接関係／2段階／すべて、から表示範囲を絞る）を切り替えられます
- **絞り込み**: 「好意」「反感」「中立」で表示する関係の種類を、所属で表示する人物を絞れます
- 人物をクリックすると詳細パネルが開き、所属・直接関係の人数・概要・主な関係（上位6件）を確認できます
- 「関係を数値で確認」（折りたたみ）で、`affinity`（親しさ）・`awareness`（認知）を含む数値付きの一覧、または人物×人物の行列表示に切り替えられます
- 編集可能な世界では、関係の行に「ラベルを編集」ボタンが出ます。一方向（source→target）ごとにラベル文字列（120文字まで）を設定・削除できます（数値の `affinity`/`awareness` 自体はここでは編集できません）
- 人物の詳細編集（「詳細設定・設定ファイルの編集窓口」から）では、人物の**所属**（`affiliation`、120文字まで、任意）も設定できます。相関図の色分け・グループ分けはこの値を使います

設定に不備（関係の形式が壊れているなど）があれば、「設定の確認」（折りたたみ）に件数と内容が表示されます。

## 予定イベントと強制行動 { #scheduled-events }

「時間」タブでは、実行日数・1日の時間帯に加えて、世界の**予定イベント**（`scheduled_events`）を確認・編集できます。予定イベントは、指定した日・時間帯に自動で起きる出来事（対象・効果・ラベル）です。

このうち**強制行動**（`force_action`）を持つイベントは、その時間帯の対象の行動そのものを、指定した動詞・引数へ強制的に差し替えます（例: 3日目の朝、主人公を強制的に「道中」へ移動させる）。画面のフォームは、動詞ごとに指定できる引数の種類・個数を案内します。詳しい仕様（バリデーションの規則など）は[テンプレート](../reference/templates.md#scheduled-events)を参照してください。

## 世界の自己拡張 { #world-expansion }

GA 実験を回す中で、人物の行動が同じ場所で何度も「空振り」する（例: 調べても何も出てこない）ことが続くと、WorldBloom はその世界に足りない要素（場所・品・事実など）を自動的に提案します。この提案は世界設定を直接書き換えず、**承認するまで反映されません**。

世界設定画面の「世界の概要」タブ、および該当する実験の結果画面に、提案ごとのカードが表示されます。カードには次の情報があります。

- **何が増えるか**: 追加される場所・品・事実の内容（例: 「場所『◯◯』を『△△』の一部として足す」）
- **きっかけ**: どの実験のどの場所でどの行動が何回中何回空振りしたか
- **検査の結果**: 静的ゲート（ルール違反の有無）と試走（holdout seed での再現確認・契約検査・到達の変化）の結果
- **書き手の説明**: 提案を作った側の説明文（参考情報。判断は上の検査結果で行う）

承認できるのは、静的ゲートを通過し、holdout seed で試走済みで、状態が「人の確認待ち」になっている提案だけです。承認時は10文字以上の承認理由を入力します。承認すると、その提案はその世界の以後の実行に反映されます。却下すると提案は使われません。

承認済みの拡張は「後から生まれたもの」節に適用順で並びます。まとめて「承認済みの拡張をすべて提案中へ戻す」こともできますが、1件だけ戻すことはできません（あとの承認は前の承認済み拡張がある前提で検査されているため）。戻すと、戻した分はすべて検査からやり直しになります。
