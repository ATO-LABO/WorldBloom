# 文章を生成する

出来事の生成そのものに LLM は関与しません。LLM が働くのは、[Sifting](../concepts/sifting.md)で採用した候補を**あらすじ**にする段階と、そのあらすじを**本文**にする段階だけです。生成前に、⚙ 設定で LLM の接続先を選んでおく必要があります（[LLM バックエンド](llm-backends.md)を参照）。

## 種別

| 種別 | 内容 |
|---|---|
| あらすじ生成（synopsize） | 格子の各ランから注目場面を抜き出し、短いあらすじを書かせる |
| 上映生成（narrate） | 採用した候補だけを、長い本文にする |

## 生成の流れ

1. [結果を読む](read-results.md)の候補一覧・詳細から、生成したい候補を選びます（あらすじは格子の代表候補全体、本文は採用済みの候補が対象です）
2. 確認画面で内容（対象数・生成設定）を確認し、「この内容で生成を開始」を押すと生成ジョブが始まります。**この操作をするまで LLM は呼び出されません**（一覧・詳細を開いただけでは生成されません）
3. 生成ジョブの進捗は一覧・詳細画面をポーリングして確認できます。サーバーに接続できないときは「サーバーに接続できません（再試行中）」と表示されます
4. 生成が終わると、候補ごとの結果が確認できます

## 候補ごとの状態

| 状態 | 意味 |
|---|---|
| 未開始 | まだ生成していない |
| 生成中 | 実行中 |
| 本文あり | 生成に成功した |
| プロンプトのみ | 本文は生成せず、プロンプトだけ保存した（LLM 接続先を「生成しない」にしている場合） |
| 失敗 | 生成に失敗した |
| 結果不明 | LLM を呼び出したが、成功したか失敗したか確定できない（後述） |
| 上限で未開始 | 呼び出し前に上限（生成数の上限など）に達した |
| 停止で未開始 | ジョブを停止したため未開始のまま |
| 中断で未開始 | ジョブが中断したため未開始のまま |

ジョブ全体の完了状況は「全件生成」「プロンプト保存のみ（本文未生成）」「本文とプロンプトの混在」「一部成功」「一部成功（結果不明あり）」「結果不明（失敗確定ではない）」「呼出し前に上限到達」「失敗」「停止」「中断」のいずれかで表示されます。

## 失敗・結果不明時の再試行 { #retry }

状況に応じて案内される再試行方法が変わります。

- **問題を解消してから『未生成・失敗分を生成』で新規要求できます**: 設定ミスなど、原因が明らかで安全にやり直せる場合
- **結果不明です。二重生成の可能性を確認したうえで『結果不明の候補を確認して再生成』から明示的に再生成してください**: LLM 呼び出し後に成否が確定できなかった場合。同じ内容が二重に生成される可能性があるため、確認したうえで明示的に操作する必要があります
- **保存障害。LLM は再送せず『復旧』で保存済み証跡から復元します**: 生成自体は成功しているが保存に失敗した場合。LLM を呼び直さず、保存済みの証跡から復元します
- **上限に達しました。上限を見直した新しい設定版で新規要求してください**: 生成数などの上限に達した場合。ここでの「設定版」は GA の実行設定ではなく、⚙ **全体設定**の「文章生成」タブにある「生成の上限」（[設定](settings.md#output-settings)を参照）を指します。値を見直して保存すると、その保存が新しい設定版になり、以後の生成要求に使われます

## 旧実験の文章化用設定を使い回す

文章生成の設定（接続先・モデル名・上限など）は実行設定（GA の設定）とは別に、⚙ **全体設定**の「文章生成」節に保存されています（[設定](settings.md)を参照）。実験ごとに個別の生成設定を持つわけではないため、別の実験で生成する際も同じ設定がそのまま使われます。設定を変えたい場合は、生成前に ⚙ 設定を開いて変更してください。
