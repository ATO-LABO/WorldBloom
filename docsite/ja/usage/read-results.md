# 結果を読む

GA 実験が終わる（または途中で止める）と、その実験の結果は QD 格子として画面に表示されます。ここでは画面での読み方を説明します。仕組み自体は[QD 格子](../concepts/qd-map.md)と[Sifting](../concepts/sifting.md)を参照してください。

## QD 地図

行が**主導カテゴリ**（I〜VI）、列が**起伏（volatility、low/mid/high）**の格子です。マスが埋まっているほど、その組み合わせの物語が見つかっていることを示します。マスをクリックすると、そのマスに残っている代表候補（最も品質 q が高いラン）の詳細が開きます。

画面上部には実験全体の指標が出ます。

| 指標 | 意味 |
|---|---|
| 占有マス | 格子が埋まった区画の数。多いほど違う種類の物語が見つかっている |
| 相異度 | アーカイブに残ったラン同士がどれだけ違う経路を通ったかの平均。1に近いほど多様 |
| 到達率 | その世代の全ラン（個体数×seed数）のうち、結末に届いた割合 |
| q̄ | アーカイブ全体の品質 q の平均 |

## 候補の詳細（Sifting の3タブ）

マスを開くと、候補の詳細が3つのタブに分かれて表示されます。

- **物語**: あらすじ（生成済みの場合）、結末、詳しい根拠・生成状況へのリンク
- **選択とメモ**: 選定状態（✔採用／⏸保留／✖除外／○未分類）とメモの入力欄
- **実験データ**: 候補ID・世代・個体・seed・到達・原記録（`layers.jsonl`）へのリンクなど

候補の一覧画面では、それぞれの候補について次の列が確認できます。

| 列 | 意味 |
|---|---|
| 傾向 | その個体の遺伝子がいちばん重みを置く行動カテゴリ（主導カテゴリとは別の値） |
| 到達 | このエリートが評価されたseedのうち、結末に届いた回数 |
| 原記録 | あり／剪定済み／不在／不一致。「あり」なら本文生成と原ログ閲覧ができる |
| 採用可 | 本文生成に使える条件（到達済み かつ 原記録あり）を満たすか |
| 稿 | この候補から生成済みの本文の数 |

## 選択・根拠・代償・転機

候補の詳細には、ある選択が「どの信念を根拠に行われ、何を失い、後続の何につながったか」をログから機械的に抽出した4項目（選択・根拠・代償・転機）が表示されます。物語の中の重要な決定を、あとから読み解くための手がかりです。

## 比較・系譜・転機の可視化

候補一覧から異なる区画の代表候補を2〜4件選ぶと、比較画面が開きます。比較画面も「あらすじ」「選択・根拠・代償・転機」「実験データ」の3タブで、実験データタブには候補ID・区画・世代・seed・品質・結末・原記録が並びます。また、候補の詳細から系譜・転機の可視化に進めます。

- **系譜（主系）**: そのエリートから親をたどった一本道。世代を遡って、どの決定が積み重なってこの物語になったかを確認できます
- **転機**: 系譜上の隣り合う親子を同じ乱数の種で再実行し、主人公の決定が最初に分かれた地点を示します。「なぜこの物語になったのか」を、進化の履歴として辿れます

再現できなかった祖先がある場合は、その理由（再現エラー）が表示されます。

## 実行履歴と削除

実行を開始すると「履歴」に記録が残り、あとから見返せます。実験が不要になった場合は、実験一覧の「削除」ボタンから削除できます。削除すると、その実験に紐づく候補・選定状態・生成済み本文・世界の自己拡張の提案などが連鎖的に削除されます（元に戻せません）。
